# Hydrometeorology EDA

This EDA focuses on Northern Bahr el Ghazal's five Aweil counties. It tests the feasibility of a seven-day flood-extent warning from ERA5 rainfall/runoff and Dartmouth discharge, and estimates the crop and rangeland exposed during different agricultural phases.

## Running the notebook

1. Install the packages in [`requirements.txt`](../requirements.txt) in the project Python environment.
2. Put the supplied data in the repository's `raw_data/` folder and make sure the processed ET file can be created in `processing_data/evapotranspiration/`.
3. Open [`hydrometeorology_eda.ipynb`](hydrometeorology_eda.ipynb) in VS Code with the Python and Jupyter extensions.
4. Select the project environment as the kernel and run all cells.
5. Results are written to [`outputs/tables/`](outputs/tables/) and [`outputs/figures/`](outputs/figures/).

The notebook processes 2024 by default so Run All completes quickly on the project environment. It produces a lag-correlation heatmap, a weekly rainfall/moisture/flood-signal chart, and four seasonal crop/rangeland exposure maps for August versus October-November. Change `YEARS` in the setup cell to `np.arange(2015, 2026)` for the recommended multi-year analysis.

Run the checks without loading raw data:

```bash
python -m EDA_hydrometeorology.check_hydrological_analysis
```

## Analysis tracks

### Seven-day forecast feasibility

- Flood detections are assigned to the five Aweil counties using `ssd_admin2.geojson`.
- ERA5 rainfall and runoff are averaged over the counties and over a westward upstream comparison box.
- The supplied South Sudan Dartmouth station is area ID 100205 at 9.6 N, 31.6 E. It is used as a river-discharge signal; no second South Sudan gauge is available in the supplied station metadata.
- Correlations compare signals at `t-k` with active flood pixels at `t` for `k = 0...14`. The highlighted day 7 column directly tests the proposed forecast window.
- Rolling 3-, 7-, 14- and 30-day rainfall-minus-ET0 features are generated in `moisture`; the notebook visualises the seven-day feature.

### Agricultural exposure

- MODIS flood points are sampled against the supplied crop and rangeland masks.
- Repeated MODIS detections are deduplicated to 500 m agricultural-mask cells before exposure is calculated.
- August represents the vegetative-growth comparison; October-November represents maturation and harvest.
- Recurring and unusual flood classes remain separate in the output table so regular flood-recession water can be distinguished from unusual shocks.

The main outputs are:

- `outputs/figures/aweil_lag_correlation_heatmap.png`: rainfall, runoff and discharge correlations for delays 0-14 days.
- `outputs/figures/aweil_forecast_signals.png`: weekly rainfall, seven-day net moisture and active flood pixels.
- `outputs/figures/aweil_seasonal_agricultural_exposure_maps.png`: August versus October-November crop and rangeland exposure by county.
- `outputs/tables/aweil_monthly_agricultural_exposure.csv`: monthly exposure percentages split by county and recurring/unusual flood type.
- `outputs/tables/aweil_flood_observation_quality.csv`: July-September detected-pixel coverage and cloud summary.

## Methods and limitations

- ERA5 `tp` and `ro` are supplied in m/day and converted to mm/day.
- The water balance is `P - ET0`, where ET0 is reference ET from one processed grid cell. It is not a closed catchment balance because actual ET and storage change are unavailable.
- The runoff coefficient is `ro / tp`; it is undefined when precipitation is zero.
- Percentile thresholds are calculated over the selected daily record. Event durations count consecutive dates above a threshold.
- Lag correlations use overlapping daily observations. Positive lag values shift the second series later; irregular lake observations need separate resampling before daily correlation.
- Flood masks are three-day composite detections, not a complete daily zero-valued raster. A day without detected pixels is not proof that the satellite observed dry land. `recurring` and `unusual` are product classes, not direct severity measures.
- The agricultural result is a detected-pixel overlap proxy, not a complete inundation polygon or crop-loss estimate. It is suitable for ranking counties and seasons for field validation.
- The supplied agricultural masks describe land fraction, not crop type or yield. Sorghum, millet and rice cannot be separated with these files alone.
- Cattle density is available in `raw_data/farmland/geonode__cattle_gha.tif`, but it is a static coarse raster and is not yet used to estimate herd displacement.
- Lake quality checks use positive readings and flag non-zero instrument, ice and source flags. Victoria and Kyoga coverage in the supplied files is incomplete after 2002.
- The ERA5 spatial output is a gridded table ready for joining or plotting against `ssd_admin2`; it does not silently assign coarse ERA5 cells to counties.
